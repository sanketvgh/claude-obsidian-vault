# IMF Framework — Overview

## What IMF is

IMF — **Index, Maps of Content (MOCs), Fluid Frameworks** — is a note-organizing method created by Nick Milo in 2020, later renamed **LYT (Linking Your Thinking)**, then **Ideaverse**. Same acronym as the International Monetary Fund; unrelated.

It fixes two opposite failure modes:

- **Folders are too rigid.** A note lives in exactly one folder, so related ideas filed under different topics never connect.
- **Plain links are too flat.** A vault that's just note-to-note links has no way to zoom out once it grows past a couple hundred notes.

The fix: keep individual notes atomic (one idea each) and richly linked, then layer a small set of **maps** on top for navigation — Milo calls maps and the one home note "Fluid Frameworks," meaning structure that helps without locking anything in place. A map is cheap to change: a note can sit on several maps at once, and reorganizing means editing a map, not moving a file.
