# About this folder

`Coffee Brewing` is a fully worked example of the IMF Framework spec (see `Docs/IMF Framework/`) — one populated domain, every note type, wired together exactly like a real vault would be:

- `+ Inbox` — one raw, unprocessed capture
- `Sources` — one source note
- `Atlas` — 5 concept notes + 1 MOC (enough to hit the "mental squeeze point" that justifies the MOC)
- `Calendar` — one daily note
- `Efforts` — one project note
- `Home.md` — the domain's own entry point

Nothing in here is real content — it's a reference for what a populated domain looks like end to end. Safe to delete, or copy as a starting pattern for a real one.
